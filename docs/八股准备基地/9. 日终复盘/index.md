# 9. 日终复盘

这里沉淀每天的复习收口结果，由 `bagu-closer` 生成。

## 这个目录负责什么

- 记录今天真实推进了哪些来源。
- 记录今天最虚的 3 个点。
- 固化明天四个动作，其中只有上午第一小时会写具体内容，其他三个动作写执行规则。
- 作为次日复习的起点，不替代卡片 frontmatter 和 `8. 拷问记录`。

## 使用约定

- 每天一篇：`YYYY-MM-DD-日终复盘.md`
- `bagu-closer` 在夜间执行，最好放在当天学习结束、`/grill-me` 之后。
- 如果当天存在纯 NotebookLM 阅读、但本地没有织网或 grill 证据，允许 `bagu-closer` 先补问一次今天推进了哪些来源。
