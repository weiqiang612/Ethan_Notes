2. 数据库索引

   * 使用 B+ 树索引，支持范围查询的同时，压缩树高，减少磁盘 IO，一般只需要 3-4 次磁盘 IO
   * 索引主要有两类
     * 主键索引（聚簇索引）：叶子结点拥有该行全部数据
     * 二级索引：非主键索引，叶子节点有主键值和本字段值，如果查询字段不为这两者，就会使用主键值再进行一次查询，即回表；由此有了一种叫做 覆盖索引 的东西，即本次查询叶子结点中是有所有所需的字段的

   * ACID 特性：原子性、一致性、隔离性、持久性
