1. Java 基础后端方向：
   * Spring 核心：IoC、AOP、事务传播、事务失效、循环依赖、动态代理
   * MySQL：索引、B+ 树、联合索引、最左前缀、慢 SQL、事务隔离级别、MVCC、间隙锁、死锁
   * Redis：基本数据结构、缓存穿透/击穿/雪崩、分布式锁、Redission、延迟队列、Stream、热点 Key、大 Key
   * 并发与 JVM：线程池、锁、voliatile、CAS、ThreadLocal、CompletableFuture、JVM 内存结构、GC 基础
   * 项目工程问题：幂等、限流、降级、重试、唯一约束、状态机、权限校验、日志审计、接口安全
2. Agent 通用基础
   * RAG：文档解析、分块、Embedding、向量检索、BM25、Hybrid Search、RRF、Reranker、Query rewrite、引用溯源、拒答策略
   * Memory：短期记忆、长期记忆、摘要记忆、用户画像、记忆注入策略
   * Tool Calling：工具定义、参数 schema、权限校验、风险二次确认、工具调用失败处理
   * Agent Loop：模型思考、调用工具、观察结果、更新状态、继续决策、终止条件和最大轮次限制
   * Workflow / Graph：状态节点、条件边、人工确认、中断恢复、任务状态持久化
   * Observability：记录 prompt、工具调用情况、token、时延、召回片段、最终回答、失败原因
