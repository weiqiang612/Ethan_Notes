## 1. 用户回答摘要
- **第一题**：准确指出了无论是基本数据类型还是引用数据类型，传递的都是“拷贝”。一个是字面量值的拷贝，另一个是地址值的拷贝。并且点出了“通过地址拷贝修改属性，原对象也会变”。
- **第二题**：完美答出形参和实参虽指向同一地址，但本身是独立的。给形参重新赋值相当于让它指向其他地址，不影响外部实参。

## 3. 推荐答案与项目口径 (标准参考)
> **“Java 中只有值传递，完全没有引用传递。”**
>
> 无论是基本类型还是引用类型，方法接收到的都是**实参的一个副本**。对于基本类型，拷贝的是具体的字面量值；对于引用类型，拷贝的是对象在堆中的**内存地址值**。
>
> 这就解释了为什么我们在方法内部**可以通过形参去修改对象的内部属性**（因为形参和实参指向同一个堆对象），但如果我们在方法内部**给形参重新赋值（比如 `param = new Object()`）**，这仅仅是改变了局部形参的指向，外部的实参变量完全不会受到影响。
>
> Java 这样设计，最核心的考量就是**安全性**，防止外部方法破坏或篡改调用方底层的核心变量引用。
