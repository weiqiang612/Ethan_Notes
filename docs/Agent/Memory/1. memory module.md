# 记忆模块

### 高层设计回顾

![image-20260510094240529](https://gcore.jsdelivr.net/gh/weiqiang612/My-TuChuang@main/img/Redis/image-20260510094240529.png)

大致有四种记忆类型，作用和存储技术总结如下：

| 记忆类型                          | 作用                                    | 存储方式/特点                  |
| ----------------------------- | ------------------------------------- | ------------------------ |
| **工作记忆 (Working Memory)**     | 当前对话上下文、工具结果、部分计划                     | 保存在 LLM 的上下文窗口中；快速、临时、有限 |
| **情节记忆 (Episodic Memory)**    | 记录过去的交互和事件，支持跨会话回忆                    | 向量数据库（用于语义检索）或按时间顺序存储和检索 |
| **语义记忆 (Semantic Memory)**    | 事实、文档、领域知识                            | 向量数据库，通过相似度搜索获取信息        |
| **程序化记忆 (Procedural Memory)** | “怎么做”：系统提示、工具 schema、few-shot 示例、行为模式 | 结构化存储或文件；通常更静态           |

**记忆路由器 (Memory Router)** 的角色：

- 每轮对话判断 **写入**（存储新信息）
- 每轮对话判断 **读取**（获取相关上下文注入 prompt）
