   6. VUE和React两种前端框架的特点对比：
   vue前端框架特点：
   渐进式框架：可逐步引入，从简单的视图层库到完整框架；
   模板语法友好：使用类似 HTML 的模板语法，学习曲线平缓；
   响应式数据绑定：基于 Proxy 的自动依赖追踪，数据变化自动更新视图；
   单文件组件：将模板、逻辑、样式集中在 .vue 文件中
   
   React 的特点
   声明式 UI：通过 JSX 声明组件结构，UI 随状态变化；
   组件化思想：组件复用性强；
   单向数据流：数据从上向下传递，状态可预测；
   函数式编程：Hooks 让函数组件拥有状态和生命周期
   
   7.MVC框架将应用分为三个核心组件：
   模型（Model）：负责业务逻辑与数据操作，封装数据规则并与数据库交互。它不依赖视图和控制器。
   视图（View）：负责用户界面展示，接收模型数据生成HTML/JSON等输出。视图不处理业务逻辑。
   控制器（Controller）：接收用户请求，调用模型处理业务，再选择合适的视图进行响应。
   相互关系：控制器接收请求 → 调用模型获取或修改数据 → 将数据传递给视图 → 视图渲染结果返回给用户。模型变化时通常会通知视图更新（观察者模式）。三者分离降低了耦合，提高可维护性。
   
   8. 5种JSP内置对象及其作用域
   request
   作用域：Request（一次请求，可经转发传递）
   封装客户端请求数据（参数、头、属性等）。
   
   response
   作用域：Page（仅当前页面响应）
   封装服务器对客户端的响应操作（如重定向、设置头信息）。
   
   session
   作用域：Session（同一用户多个请求期间）
   存储特定用户会话期间的私有数据（如登录信息）。
   
   application
   作用域：Application（整个 Web 应用，所有用户共享）
   存储全局数据（如计数器、配置参数），对应 ServletContext。
   
   pageContext
   作用域：Page（仅当前 JSP 页面）
   代表页面运行环境，可获取其他所有内置对象，并能将数据存储到 page、request、session、

   	public void destroy() {}
   	
   	public void doFilter(ServletRequest request, ServletResponse response,
   			FilterChain chain) throws IOException, ServletException 
   	{
   		String servletPath = httpRequest.getServletPath();
   		if (servletPath.endsWith(".jsp"))
   		{
   			request.setCharacterEncoding("UTF-8");
   			chain.doFilter(request, response);
   		}
   	}
