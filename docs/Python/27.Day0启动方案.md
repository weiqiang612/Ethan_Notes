# Day 0 启动方案

> Day 0 的意义是把学习体系切换为一个可运行、可验证、可追溯的工程仓库。完成后才进入 Week 1 Day 1。

## 一、Day 0 完成定义

    python-agent-engineering/
      → Git 仓库正常
      → Python 3.12 环境可运行
      → uv、pytest、ruff 可运行
      → AI Prompt 与学习记录可直接使用
      → 首个测试通过
      → 首次提交已存在

## 二、固定技术选择

| 项目 | 选择 | 原因 |
| --- | --- | --- |
| Python | 3.12 | 生态成熟，兼容本训练中的 Agent 相关库 |
| 依赖管理 | uv | 已在 Week 2 统一为 pyproject.toml、.venv、uv.lock |
| 测试 | pytest | 后续 Fake Client、Policy 与工作流测试需要它 |
| 格式化与静态检查 | ruff | Day 0 只保留一个基础工具 |

**不混用** venv 手工创建、pip 安装、requirements.txt、Poetry 或 Conda。uv 会管理项目虚拟环境与锁文件；项目命令统一通过 uv run 执行。

## 三、执行顺序

### 1. 创建仓库骨架

仓库名固定为 python-agent-engineering，定位为 Agent Engineering Lab，而不是学习代码集合。

    python-agent-engineering/
    ├── README.md
    ├── docs/
    │   ├── ai/
    │   ├── learning-log/
    │   └── roadmap/
    ├── labs/
    │   └── week01-python-core/
    ├── projects/
    ├── evaluations/
    │   ├── datasets/
    │   └── reports/
    ├── scripts/
    └── .gitignore

README 第一版只写 Goal、Background 和 8 周路线；不要在 Day 0 写复杂架构说明。

### 2. 初始化项目与开发依赖

在仓库根目录执行：

    git init
    uv init
    uv python pin 3.12
    uv add --dev pytest ruff

随后以 uv run 创建或同步 .venv 与 uv.lock。若本机没有 Python 3.12，先安装或让 uv 提供该版本，再继续；不要悄悄切换到未知版本。

### 3. 建立最小代码与测试

创建 labs/week01-python-core/day01-env：

    day01-env/
    ├── main.py
    └── tests/
        └── test_main.py

最小行为：hello 返回 Python Agent Start；测试断言该返回值。运行：

    uv run pytest
    uv run ruff check .
    uv run ruff format --check .

Day 0 不追求业务意义；它证明解释器、依赖、测试与质量工具连接正确。

### 4. 迁入 AI 工作流入口

创建 docs/ai：

- daily-review.md：当天 Review 的输入与结论；
- design-review.md：大模块开工前的设计挑战；
- prompts.md：链接或复制导师、Reviewer、Architect、Interviewer 模板。

将第 12 号 SOP 和 prompts 目录作为来源；不必为同一 Prompt 维护多个不一致副本。

### 5. 建立 Day 0 基线记录

创建 docs/learning-log/day00.md，记录：当前背景、目标岗位、已有能力、Python 短板、工具版本、今日验证结果和 Week 1 的最小目标。

### 6. 进行首次提交

只有在最小测试和质量检查通过后，执行：

    git add .
    git commit -m "docs: initialize python agent engineering roadmap"

这条提交是学习证据的起点，不等待业务代码完成。

## 四、Day 0 验收

- Python 版本为 3.12；
- pyproject.toml、uv.lock 和 .venv 的职责清楚；
- uv run pytest、uv run ruff check .、uv run ruff format --check . 均成功；
- README、.gitignore、目录骨架、AI 入口和 day00 记录存在；
- git log 可看到首次提交；
- 没有 API Key、真实数据或本机敏感配置进入 Git。
