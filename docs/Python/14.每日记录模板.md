# 每日学习记录模板

> 一天一份。重点记录自己的工程判断、失败原因和验证证据，而不是学习流水账。

    # Day {编号}：{主题}

    ## 今日目标

    - 今天要证明什么？

    ## 学习输入

    - 官方资料：
    - 只需回答的问题：

    ## 自主实践

    - 修改或新增的模块：
    - 实现了什么：
    - 验证命令与结果：

    ## 设计思考

    - 我为什么这样设计？
    - 一个可行替代方案及不采用它的原因：

    ## 失败与根因

    - 现象：
    - 根因：
    - 如何防止再次发生：

    ## AI Review 结论

    - AI 提出的关键问题：
    - 我采纳的修改及证据：
    - 我拒绝的建议及理由：

    ## 明日最小目标

    - 只写一个可以验证的目标。

## 最低完成标准

- 至少一项自己的代码、测试或设计产出；
- 至少一个可复现的验证命令或手工步骤；
- 至少一个设计取舍或失败根因；
- 不写“已掌握”，除非能列出对应证据。
