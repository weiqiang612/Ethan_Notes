### 编码实践

## Day 6：类设计与 Router

### 今日目标

使用类封装 Router 的注册与分发职责，并理解 Python 对象生命周期与 Spring Bean 的边界差异。

### 学习输入

- Python Tutorial：`Classes`
- 重点：`class`、`self`、`__init__`、实例属性、方法调用；不深挖继承体系。

### 编码实践

在 `day06-router-class/` 实现：

```python
class ToolRouter:
    def __init__(self) -> None:
        self._tools = {}

    def register(self, name: str, handler) -> None:
        ...

    def dispatch(self, intent: str, params: dict) -> dict:
        ...
```

要求：未知意图返回统一错误；只读工具可以直接分发；写操作返回“需要确认”的草稿，不执行实际写入。

### AI 辅助任务

### 验收检查

- 能解释 `self` 指向实例而非类。
- 能解释为何 Router 只负责分发，不负责实现所有业务工具。
- 能处理未知 intent 与重复注册。

### 当日产出
