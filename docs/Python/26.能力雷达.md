# 能力雷达与证据面板

## 使用目的

能力雷达不是自我打分表，而是每周发现“没有证据的能力声明”和下一步最小补强点的工具。每项只按证据状态更新。

| 状态 | 含义 |
| --- | --- |
| 0：未开始 | 没有学习或实现 |
| 1：理解概念 | 能解释概念，但没有独立代码证据 |
| 2：最小实现 | 有代码，但测试或边界不足 |
| 3：可验证 | 有测试、Demo 或设计记录，可解释取舍 |
| 4：可面试表达 | 能回答追问，有失败案例与证据链接 |

## 使用规则

1. 不填百分比，不用感觉替代证据。
2. 状态从 2 升到 3，至少要新增一项测试、演示或 ADR。
3. 状态从 3 升到 4，必须经受一次追问或模拟面试，并记录无法回答的问题。
4. 一周只选择一个最低、同时最影响目标岗位的能力作为补强 P0。

## 可视化方式

当表格中各项都有证据后，再任选电子表格或笔记插件生成雷达图；图只展示状态，不替代链接和具体证据。没有证据的高分会掩盖风险，因此默认保留表格。
