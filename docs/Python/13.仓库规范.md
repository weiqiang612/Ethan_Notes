# Python Agent Engineering Lab：仓库规范

## 定位

仓库是持续演进的 Agent 工程实验室，不是直接开写最终项目的目录。它保存独立练习与测试证据、验证后迁入项目的代码，以及设计、评测、演示和面试表达资产。

## Lab 进入 Project 的门槛

- 有清楚的输入、输出、状态和失败路径；
- 有自动测试或可重复演示；
- 已写明为何适合项目，而不是仅因学过；
- 不含密钥、真实敏感材料和本机绝对路径；
- 依赖和运行方式可在 README 复现。

## 最终作品边界

最终作品为法律案件研究工作流 Agent（v1：劳动争议）。模型提议研究动作和归纳材料；后端负责来源策略、引用绑定、状态更新、敏感信息边界与人工升级。它不是律师服务，也不是通用搜索 ChatBot。详见 [[30.法律案件研究Agent项目蓝图]]。
