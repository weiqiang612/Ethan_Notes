# 任务优先级矩阵

## 定义

| 级别 | 定义 | 执行规则 |
| --- | --- | --- |
| P0：不可牺牲项 | 缺失会破坏后续路线、面试核心表达或最终作品闭环 | 必须完成；只能缩小范围，不能删除 |
| P1：核心增强项 | 明显提升质量或理解，但不阻塞主链路 | 时间不足时压缩或延期 |
| P2：扩展项 | 有价值的探索、优化或比较 | 有余量才做，默认进入 backlog |
| P3：暂缓项 | 会造成范围失控且当前没有明确收益 | 本训练周期明确不做 |

## 排序公式

新任务进入计划前，先按顺序判断：

1. 是否服务一个 P0 能力？
2. 是否能产出可复现的项目或面试证据？
3. 是否比现有未完成任务更高价值？
4. 是否会引入新的不可控依赖或范围？

若前两项都不是“是”，或第四项是“是”，默认放入 P2/P3，不插入本周。
