## 架构图规范

每张图必须回答三件事：数据怎么流动、控制在哪里、状态在哪里。图旁必须有一段说明，不只放漂亮图。

建议保存在 docs/architecture：

| 文件 | 回答的问题 |
| --- | --- |
| system-overview.md | API、Runtime、Tool、持久化和评测如何协作？ |
| tool-flow.md | 模型建议到策略校验、执行和回传如何流动？ |
| research-flow.md | 从事实澄清、检索、来源核验到备忘录如何流动？ |
| state-machine.md | 缺失事实、待核验来源、补料和升级如何迁移？ |
